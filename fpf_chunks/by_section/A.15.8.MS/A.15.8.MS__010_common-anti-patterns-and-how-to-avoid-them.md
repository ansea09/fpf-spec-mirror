### A.15.8.MS:8 - Common Anti-Patterns and How to Avoid Them

| Anti-pattern | Repair |
| --- | --- |
| “The Method Base is the repository.” | Identify the collection, membership rule, edition, publication, access, task set, and observed uses separately. |
| “The profile row chose the support arrangement.” | Use the row only for its representation/action claim group; compare and select support configurations in A.15.8.MS. |
| “C.37 selected the representation, so the task passed.” | Keep use-bounded disposition separate from performed Work and the receiving task result. |
| “The PLM route passed, so manual lookup is insufficient.” | Record PLM as observed pass and manual lookup as untested unless a declared missing feature proves insufficiency. |
| “Choose the smallest arrangement for each task and combine them.” | Check shared currentness, maintenance, confidentiality, latency, authority, and provider effects; return a retained set or stated split when the union has no supported order. |
| “The interface gives users access.” | Establish the access relation and relevant permission; an interface is only one System or presentation element. |
| An AI-use label leaves its contribution to a decision unclear. | For a claim that AI contributed to a decision, identify the AI System interaction, contribution used and resulting decision. Identify a provider interaction or review when it occurred or is required, and establish any required permission and authority. A missing required premise limits the dependent claim or use. Identify dated Work only when the claim needs that occurrence. |
| “All components are listed, so the structure is selected.” | Establish all four A.22 discriminators for the named use; keep the proposal where that claim is not supported. Dated selection Work is a separate claim. |
| “Three users passed, so the team is capable.” | Report the three Work-task observations and evaluate capability under `A.2.2` only when its holder, Work family, envelope, measures, and window are present. |
| Feedback availability is confused with its occurrence or use. | Establish the usable channel for an availability claim. Identify the feedback and its recipient for an occurrence claim, and its contribution to the receiving result for a use claim. Supply Work or SpeechAct grounds when claiming those kinds. |
