### C.35:7 - Conformance checklist

| Check | Pass condition |
| --- | --- |
| `CC-C35-1` | A sentence or four-line statement names the result, the organization concerned and whether the claim about it is established, refuted or unestablished, or presents a proposal, the supported next use and any unresolved condition, material limitation or required return. This is a conforming first result. |
| `CC-C35-2` | An optional materialized note has the result as its EntityOfConcern and repeats the readable minimum. It adds identity, representation, publication, project-use, branch, Method, Work, attribution, bearer, evaluation, or next-claim fields only when the receiving use relies on them. Any present publication-form, publication-occurrence, or presentation-carrier reference identifies the corresponding form, occurrence or carrier; absent publication apparatus creates no field-filling duty. |
| `CC-C35-3` | When branch evidence is relied on, the branch is selected for each claim; distinct operations in a complex result retain their separate bases. Transformation supplies source and result objects, trace, preservation, and loss; discovery supplies observation or extraction basis, what is observed, what is inferred, what remains unknown, coverage, uncertainty, and validation; generative proposal supplies constraints, proposed organization content, omissions, and validation needs, with source and preservation only for a declared baseline. |
| `CC-C35-4` | A positive structure reference passes all four A.22 discriminators. An unestablished claim about existing organization remains unresolved; a refuted claim stays refuted; a proposal stays modal. C.32 may use a qualified provisional result without treating an unestablished or proposed organization as obtaining architecture. |
| `CC-C35-5` | Bearer or realization detail appears only when the intended use relies on feasibility or realization; any such question uses the rule that defines or tests it. |
| `CC-C35-6` | Use the pattern for each archive, front, pool, publication, eval, measurement, mathematical-lens, decision, evidence, assurance, gate, release, Method, or Work claim; an absent claim creates no C.35 field-filling duty. |
| `CC-C35-7` | The first result states the supported next use and any condition, limit or return that changes reliance. A next-claim or rule reference is added only when the receiving action relies on reidentifying it independently. |
