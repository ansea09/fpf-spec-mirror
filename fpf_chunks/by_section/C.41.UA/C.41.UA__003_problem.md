### C.41.UA:2 - Problem

People can confuse doing the work, checking its result, recording an answer and authorizing a continuation. An agent can report that it implemented error handling while the catalogue was never inspected. An organizer can reuse yesterday's green summary against today's changed description.

The problem is to answer the present question on sufficient grounds, preserve what remains useful and avoid inventing certainty to finish the form.
