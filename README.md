# fpf-spec-mirror
Зеркало репозитория с [First Principles Framework]([url](https://github.com/ailev/FPF/blob/main/FPF-Spec.md)) (FPF) от @ailev. Нужно для того, чтобы настроить skills в Codex. 

В репозиторий подгружается обновлённая версия спецификации FPF, которая затем разделяется на кусочки (chunks) по кластерам паттернов. Можно настраивать skills точечно под задачи, требующие определённых паттернов рассуждения. 

Контракт обязательных паттернов и миграции при изменении upstream FPF описаны в [`docs/required-pattern-contract.md`](docs/required-pattern-contract.md).
